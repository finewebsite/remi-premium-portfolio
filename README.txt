REMI GACHOKI — PREMIUM PORTFOLIO PACK

Files:
- index.html: complete responsive portfolio website.
- Remi_Gachoki_Premium_Portfolio.pdf: shareable PDF portfolio.

Publish the website:
1. Open https://app.netlify.com/drop
2. Extract this ZIP on your computer or phone.
3. Drag the folder containing index.html onto Netlify Drop (or select that folder if prompted).
4. Wait for Netlify to publish and copy the generated URL.
5. Open the URL on a phone to check the layout and links.

The two projects are labelled as independent demonstration concepts, not commissioned client work. Keep this disclosure when sharing the portfolio.
