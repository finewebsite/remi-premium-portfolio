REMI GACHOKI — PORTFOLIO WEBSITE

FILES
- index.html: website structure and project links
- styles.css: responsive visual design
- script.js: mobile navigation
- assets/: place any additional images or assets here

HOW TO USE
1. Extract this ZIP file.
2. Upload the contents of the remi-portfolio folder to your GitHub repository (keep the three main files at the repository root).
3. Connect the repository to Netlify, or deploy the folder using your preferred static hosting service.

IMPORTANT BEFORE PUBLISHING
- Replace YOUR_EMAIL@example.com in index.html with your preferred public contact email.
- Gachoki Technical Institute is included as a clearly marked upcoming project because its separate live website URL has not yet been supplied. Once published, turn that project card into a link to its live website.
- The other project cards open their individual websites in a new tab.

The site uses Google Fonts; an internet connection is needed for those fonts. The layout and core styling work without them.
